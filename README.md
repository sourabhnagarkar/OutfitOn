# OutfitOn - Online Cloth Rental System

## Developed By
Sourabh Nagarkar

## Project Type
BCA Final Year Project

## Description
OutfitOn is a web-based Online Cloth Rental System developed using PHP and MySQL. 
It allows customers to rent clothes, vendors to manage products, and admin to manage the system.

## Features
- User Registration & Login
- Vendor Dashboard
- Admin Panel
- Add Cloth
- Booking with From & To Date
- Cart System
- Order Management
- COD Payment

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- Bootstrap
- JavaScript

## How to Run
1. Install XAMPP
2. Place project inside htdocs
3. Import database.sql into phpMyAdmin
4. Run http://localhost/OutfitOn
